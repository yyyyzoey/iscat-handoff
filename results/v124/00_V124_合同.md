## 4. 必须使用的物理前向（不可替换为经验 C）

同一个物理幅相约定和参考路径上：

\[
 I_{p,j}=\frac{1}{A_pT_j}\int_{A_p}\int_{W_j}\sum_{\alpha}|E_{\rm ref,\alpha}(\mathbf r,t)+E_{\rm sca,\alpha}(D,n_p,h,\mathbf r,t)|^2\,dt\,dA,
 \qquad I_{{\rm bg},p,j}=\text{同条件下无目标颗粒的参考/背景强度}.
\]

本批核心**静态图像观测**：

\[
 C_{p}=\frac{I_p-I_{{\rm bg},p}}{I_{{\rm bg},p}}
 \quad (I_{\rm bg,p}>0),
\]

保留符号、完整纯散射强度项、逐相机像元、背景/同曝光身份、物方实际像元平均。无颗粒场且 n_particle=nwater 的非磁均匀球极限必须 C≈0。先形成二维 `Ibg`, `I`, `C`, `Er`, `Es` 或完整可重现的等价复系数，并保存单位、偏振、NA及轴。**禁止逐样本自由调整光学参考相位、D相关增益或每颗粒振幅**。

使用经过身份与有限案例回归的工作站物理模块：`source/run_v065_three_size.m` 所用的 Fe3O4/Mie 与分层求解线，`build_system` / `render_system` / `src/prepare_nanobem.m` 等真实现有入口，固定对应 NANOBEM 上游 `ce49f77f096337db8be54c46d83696d37b0b23d5` 和本地补丁哈希。实际文件/导入路径需工作站核对；不能直接相信同名 helper 或用 `genpath` 载入一堆旧版本。

**物理计算优先级**：

A. 有可运行、可追溯的**分层 BEM + 向量矢量成像**：优先直接生成至少一个 D100/h450/np1.38 的原场与 17×17 iPSF，随后按照第6节连续执行。改变球心高度通常改变界面耦合，不能只重新贴 `sin(2kh)` 来宣称高度扫描。

B. 现有、真实实现的**单球 Mie 角振幅 + 玻璃/水 Fresnel 传播 + 矢量 pupil + 参考光**（尚未包含球—界面多次散射）若能够完整定义与 BEM 可比较的 `Er/Es` 绝对幅相，可以作为 `APPROX_ISOLATED_SPHERE_INTERFACE` 快后端；其适用范围须通过预先选定的直接分层 BEM 留出检查。**不能仅用 Mie 截面或 Qsca 就叫 iSCAT 对比度**。

C. 两条图像物理路径均不能得到合格场时，继续执行自由空间 Mie/Rayleigh 的散射截面、尺寸参数、能量/匹配极限基准，输出真实的 `Qsca(D)` 和模型失败报告；**不输出虚假的 iSCAT C、无根据的 Dhat 或实验标定**。

大小参数 `x=πnwater D/520nm` 在 D30–200nm 约 0.242–1.613，不能从 `x>0.5` 开始强行套几何光学 `Qgeo=2`。小球极限：

\[
 Q_{\rm sca}\sim\frac{8}{3}x^4\left|\frac{m^2-1}{m^2+2}\right|^2,
 \quad m=n_p/n_{\rm water}.
\]

该表达式用于独立低 x 极限检查，不是直接的 2D iSCAT C。参考：
- [ACS Photonics 2024: Unified Simulation Platform for Interference Microscopy](https://pubs.acs.org/doi/10.1021/acsphotonics.4c00621)
- [Rayleigh efficiency 对照实现](https://miepython.readthedocs.io/en/2.5.5/04_rayleigh.html)
- [Optics Express 2020: iSCAT iPSF 与轴向成像](https://pubmed.ncbi.nlm.nih.gov/32906875/)

## 5. 数值与物理资格门：最多两轮定向修复，不准改模型凑过关

1. **n 匹配连续极限**：`np=nwater+0i`，不管 D30、D100、D200，都不得除零、NaN 或出现非零物理散射；从两侧取 `np=nwater±1e-4` 时，散射场应向零收敛。精确同介质在真实代码中允许浮点残差，预注册 `max|C_match|≤1e-10` 为理想工程目标，失败按实际数值报告，不动态放宽。
2. **参考规范和量纲**：Er、Es 以同一复数场单位计算；两个场均乘相同因子时相对 C 不变。n_glass 变动后应改变 Fresnel 参考及透射、不得只改变文字。无颗粒时 C=0；Ibg>0且有限。
3. **小球独立核对**：D10/15/20nm 的孤立均匀球，使用独立 Mie 与 Rayleigh 对照；Qsca 极限和零反差/无吸收能量守恒检查。D≥60nm 不用瑞利公式代替物理真值。
4. **真实像元及坐标哨兵**：使用工作站冻结的成像约定：第一输出轴 `camera_x`、第二轴 `camera_y`；受控 +x 移动只移动对应行，禁止按真值择优转置。17×17每像元5×5对**强度**平均，q5/q7对照；改变倍率影响物方像元，不改变物镜 NA。
5. **静态 h/zf 分离**：固定 D/h 改 zf 不应无意重建不同粒径场；固定 zf 改 h 应检验球—界面耦合。不得让物理球体穿过界面。没有得到直接计算证据，不允许“BEM 对所有 h 免费复用”的断言。
6. **P0相关性审查**：已有 blocked/unblocked 相对 Frobenius 差 `2.58848e-7 > 1e-10` 是尚开放的独立数值问题。若该偏差污染拟用物理路径，其结论必须限定或阻断；不相关的历史大套件不作为所有场计算的共通永久阻断。L0/L1多设置同时变化称**联合离散级差**，不能宣称单纯网格收敛或真实解误差上界。
7. **发布和归档**：新运行后从实际配置、源码、MATLAB addpath、Python 导入文件、结果数组建立哈希与机器状态。输入缺失的某条分支只标该分支为 BLOCKED，另一路可继续；失败报告必须保存。

**数值比较目标**（供工程选型，不是实验测径承诺）：在高于数值噪底的预注册 ROI 中，BEM 两离散级的 C 相对 L2 差目标 `≤2%`（另报绝对 RMS）；经过独立物理计算得到的快/分层对照目标 `≤5%`，并报告其导致的粒径变化。近零信号时相对误差不可用，要检查绝对误差及 D 剖面是否有意义。上述门均要求真实数组和实测计算日志，不能仅由写在代码里的 flag 置 PASS。

## 6. 一轮连续执行路线（不能只跑一个 D100）

### W0. 开工、固定身份和修复 V123R1 错误路径

- 固定源 `v123r1@2c286d…`，另建 V124 执行分支/新输出目录，**保留原 `tools/v123_physics.py` 作为 rejected diagnostic，不原地覆盖**。
- 检查工作站是否已有 V123R1 当轮未提交的日志/NPZ/执行代码，读原字节。若有，按物理身份分级；不得从文字摘要推断已通过。
- 导入现有 NANOBEM 物理链与 iPSF 成像；参数集中入 `config/v124_model_and_user_inputs.json`，记录已确认/假设与源码哈希。完成第5节前置哨兵。禁止在此之后退回旧标量公式。

### W1. 最快获得**真实物理前向曲线**并持续计算

**先做一个物理 D100/h450/n1.38 样例**，提供 `Er`, `Es`, `Ibg`, 有符号 `C[17,17]`；若 2D 阵列不能生成，本阶段判 BLOCKED，绝不画伪图。随后直接完成**同一固定高度 h=450nm 的 7 粒径**：

`D=[30,50,70,100,130,160,200] nm`，相同材料/参考相位/成像/像元，输出真正的 D—对比度特征（至少带符号 PSF 模板范数、峰值带符号位置及背景归一值）。**不要只生成 D100 就停止。**

全主情景理想直接尺寸网格 `D=30,40,...,200nm` 共18节点，完整 D 轴优先于增加耗时但不能帮助估计 D 的历史检查。若有合格快后端，则继续 h=200:25:1000nm 33点和三折射率情景，产生 **18×33×3=1782个实际直接静态 2D iPSF**。不得把简单标量填充称为这些图像。

### W2. 快后端资格与受限扩库；阻断时自动用完整 BEM 备用

选择流程：

- 已存在可追溯且经过物理基准的 Mie+界面成像快后端：直接用本轮已完成哨兵和独立分层点检测。必须明确忽略界面多次散射的近似。不得用留出点拟合单个任意常数或逐粒径的增益。
- 若仅有源码框架，限定**90分钟探索/实现窗口**。超过窗口仍无合格 2D `Er/Es/C`，停止这条快后端开发，自动转 `W3` 完整 BEM 备用，不再写新 `sin`、`Qgeo` 或自己猜测的“物理校准系数”。
- 快后端基础曲线完成后，可用 `D=[35,55,85,115,145,185]nm`、`h=[237.5,512.5,887.5]nm` 预注册独立点做模型内验证。训练 h 按25nm；若训练加密到12.5nm，留出 h 改 `[231.25,506.25,881.25]nm`（**加密决策在打开留出前冻结**）。训练 h 可按相位响应作密度核验，不能只用 h=200,400,600,800,1000 的近周期步长插值。
- 对照 BEM 需覆盖最小球—界面间隙 D200/h200，中心 D100/h450，独立 D/h 及不同折射率。只有实际通过的物理范围内，才能把快库声明为 `APPROX_BEM_CHECKED_WITHIN_TESTED_SCOPE`；未过的材料/高度按条件结果、不可用于实验反演。

### W3. 没有合格快库时，**有界 BEM 备用批次，先保证 D 曲线/留出**

与 W1/W2 **共用预算**，不另开配额；已有同配置有效求解直接继承并逐项扣减。

1. `np=1.38+0i, h=450nm,zf=450nm`：`D=30:10:200` 共18个训练系统，先补齐尚未完成者（前述7节点若已存在仅取身份）；保存18张有符号空间 C 图、对应 Ibg/Er/Es、对比度-粒径曲线。
2. 固定 h450 的 6 个**不同粒径物理直接留出**：D=`[35,55,85,115,145,185]`（L1级），全部生成后冻结的训练插值反演，不得反向加入训练。
3. 对 h 变化，只在 D100 同一粒径上**额外**直接计算 h=`200:25:1000`，其中 h450 已包含在训练集，新增最多32系统；形成 D100 的多峰高度响应曲线，用于证明/量化标量模糊。**不可以从这条 D100 高度曲线推导其他所有 D 的完整 D×h 联合反演**；这条备用线的正式标定只适用于已明确高度条件，悬浮未知高度时标明 `NOT_CALIBRATED_FOR_UNKNOWN_H`。
4. 为固定高度近似做最多8个必要联合离散化/参考/修复系统，预算总最多 `18+6+32+8=64`；优先保留真正独立的 D 留出和数值检查，不为凑满64而生成无关场。
5. 如果物理后端有序但许可证/内存/时限使全部64无法完成，按**主 D 曲线 → 六留出 → 高度 D100 逐步扩展 → 数值余量**的顺序连续推进；保存每个系统 checkpoint。时间/资源触顶可合法 PARTIAL，不把未完成高度域宣称覆盖。

这一备用线能够给出真实的条件 D 曲线和独立固定高度粒径误差；它**无法**在没有合格 2D D×h 模型时认证悬浮未知高度下的单帧尺寸。

### W4. 真正的反演：三个对照方法（不要按真值挑选）

- **M0 标量基线**：固定 h=450nm 的主 ROI 峰值/幅度，反演 D。比较“忽略高度”的偏差；输入必须来自实际计算 iPSF，不是旧 `v123_physics.py` 标量。
- **M1 单帧二维图样**：在同一个有符号 C 场上联合寻找 `D,h,x,y`，固定材料情景及统一相位/幅度来源；保存全域多峰 D 轮廓、相邻高度异解、边界/拒判。
- **M2 多帧共享 D**：对同一虚拟颗粒多帧共享 D；每帧独立 h,x,y；轨迹为合格模型的观测输入，inverse **不能读取生成用真D/真h/扩散系数**。不得每帧或每粒子放任意散射幅度和相位尺度。

**前置**：只有 W2 的 D×h 多维模型物理资格成立时才做 M1/M2 正式综合验证；W3 只有固定 h 训练库时，M0 及已知高度下的条件二维 M1 可完成，但未知 h 的 M1/M2 应记 `INSUFFICIENT_DH_LIBRARY`，不能用单D高度曲线补齐。

训练插值器/边界/搜索/评分在读取独立粒径与高度留出前冻结。单帧使用整幅 17×17 C 图并保留符号，不逐图按最大值归一，不根据真D限制搜索。保存最少两组不同起点/盆地，报告多解、最小残差、D可行集合、拒判、计算边界。没有实测噪声协方差不能把确定性兼容区间称95%置信区间。

独立留出报告每个 D/h 的 `Dtrue,Dhat,htrue,hhat,abs_err_D,rel_err_D,fit_status,multi_solution,boundary,rejected`；所有失败计入总数。工程误差目标（不是物理真理）`|Dhat-Dtrue|≤max(5 nm,0.1Dtrue)`，未达到也必须报告而不是删除结果。测试原始图从直接物理计算取得，不能从训练插值表“抽样生成”当独立验证。

### W5. 真实悬浮轨迹与曝光、噪声：在合格 D×h 模型后连续完成

悬浮粒子模型应令初始坐标 `(x0,y0,z0)=(0,0,600nm)`，原V123错误的 `positions[0,0]=h0` 必须禁止。扩散系数条件模型：

\[
\mathcal D=\frac{k_BT}{3\pi\eta D_h},\qquad \Delta r_q\sim N(0,2\mathcal D\Delta t).
\]

合成研究可先设流体力学直径 `D_h=D_optical`，但标签 `SYNTHETIC_ASSUMPTION`；不可把这当实际磁核真相。球心须留在 `h≥D/2+g_min`，采用明确的反射边界构造，不能用 `max(200, h+dh)`夹断随机路径并称 Brownian。近壁阻力/磁场/重力未建模时，必须标明理想远壁近似失配，遇越过散射场支持域拒绝，不静默裁剪。

同一条保存的连续路径做 `25 μs` 与 `100 μs` 曝光：**先逐时刻计算强度，再在曝光窗积分，不能先平均复场**；从相同路径得到的两曝光图用于分离运动模糊。计数噪声按假定曝光光子数变化，不能给25与100μs赋同样电子数却宣称相机真实性。每条轨迹输出有效帧数、域外与拒判，至少保存几条完整原始复图/强度小例。

若已得 D×h 合格快库，沿用冻结实验：`D=[35,85,185]nm`、每D12条轨迹、每条8帧（共36条轨迹，25/100μs两曝光对应72段；一对曝光仍是同一条轨迹），主噪声条件背景 `10^4 e-/pix`、读噪`2e-`均为**假设**。静态留出在背景 `10^3/10^4/10^5 e-/pix` 下做每档5重复的小样本敏感性；不要为可视化而任意抬光强、不要用旧金球1506e配方声称相机实测。若 D×h 未合格，W5应转为动力学和光学场需求诊断，不生成伪图。

### W6. 真实实验接入预留（不要求用户在本轮重新提供）

未来用户提供实际NA、总倍率/量尺、相机曝光、参考/偏振、真实磁颗粒材料与制样时：

- 替换电磁参数 → 相关 BEM/Mie 及其下游失效；改变玻璃/水界面或λ也重新求有关场。
- 仅改变物方像元、收集NA、zf → 若已存充分角谱和空间支持，重成像/积分而非盲目整库重算；NA改变不能只乘一系数。
- 曝光/运动 → 保留场内重积分，超出D/h/xy支持域需增补场。
- 相机电子/DN/暗偏置/噪声 → 仅合格线性电子/DN观测层更新，重新生成测试；背景含非零偏置不能直接与理想 Ibg 分母互换。

约400Hz动态 FFT 继续保留独立观测算子合同（N=2001,Fs=5000,k0=160等），**不得用静态 signed C(D,h) 曲线直接标定 FFT 幅值**。实验中的每个磁颗粒必须先通过目标身份/背景/轨迹判定，混有金颗粒的数据不能靠大小强度直接分类。只有独立几何尺寸证据与样本匹配、相机/光路参数可信且独立实验验证完成，才能讨论绝对单颗粒几何D。

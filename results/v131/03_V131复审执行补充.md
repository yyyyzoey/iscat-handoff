## 3. 可直接执行入口与如何接续

```powershell
python -m unittest discover -s tests -v
python tools/truth_and_score.py --repo "<WORKSTATION_REPO>" --config config/v132_science_config.json --out "<WORKSTATION_REPO>/results/v132/intake"

```

`<WORKSTATION_REPO>`替换为实际路径，不把它当字面量提交。上述工具属于**前半段的已实现离线组件**：最后一个命令**正常退出3表示这部分已完成但全合同必须继续**；退出2表示读结构化错误，受影响支路阻断、其他支路继续。Codex需实现并运行合同第10节真实 MATLAB/source/直接render、`v132_run_all`全阶段协调器、完整quality gate、M、相机/运动和独立ZIP验收；不能只建这些空文件。全量代码/实际模块路径、SHA与配置冻结，防止又停在“已有脚本但未执行”。

## 1. 硬证据：哪些结论可以成立，哪些结论不能外推

### R01：12项直接render物理对照全部未通过

`results/v137/validation/same_solve_shift_F2.csv` 的每个 M 都有 `default_zero_shift` 和 `at_offset_nonzero_shift` 两个对照：

|对照|样本数|相对L2范围|工程门 1%|
|---|---:|---:|---|
|MAT默认零位移 vs F2|6|**6.43%–8.75%**|0/6|
|MAT原位移 vs F2|6|**50.34%–86.35%**|0/6|

这里可直接成立的事实是 **“在V137已发布的比较路径中，两组图像严重不一致”**。但 **不能直接认定** “F2物理插值本身导致50%–86%的误差”。可能的独立原因包括：MATLAB/HDF5图像行列/轴顺序、粒子偏移方向、摄像机取样坐标、原求解与render文件身份、或合并H5并非原同solve图。必须用原始数组依次排除。

### R02：与上述对照相矛盾的“合并H5 vs F2”近匹配

同一发布的 `physical_forward_qualification.json` 还列出F2与 `results/v132/validation/new_M_images.h5` 的对照。在**真参数处**，其中合并H5 `at_offset/C` 相对偏差约 **0.47%–2.02%**；而原MATLAB `at_offset` 的发布差异却是50.34%–86.35%。

这表明**不能在未验证观测同源之前，将原MAT与合并H5共同称为“同一个直接L1物理观测”**。V137报告将合并H5称为F2替代渲染，是需要验证的强烈线索，不是单靠两张结果表就已经证明的生成机制。

下一轮必须在相同原MAT文件、同一H5数据集、同一ROI和同一坐标约定下做逐像元对照，给出是否相同、何处不同、由哪段生成脚本导出的完整证据链。**即使合并H5与F2拟合结果很漂亮，如果它不是独立原MAT观测，不能将六M称为六个直接物理留出已验证。**

### R03：同一原render的对比度恒等式检查存在源码级错误

`tools/v137_w2_same_solve.py` 在循环读取 default、wide、at_offset 后执行：

```python
Cdef_id = np.max(np.abs(Cdef-(Itot-Iref)/Iref))
```

其中 `Cdef` 来源 default，但 `Itot/Iref` 是循环里**最后一次**读取的render数据；按正常变体次序可能来自 `at_offset`，并非 `default` 的自己的强度。**这项数值不能认证任一原render的内部强度恒等式。**

V138必须分别对每个文件单独核对：

\[
C^{(v)}_{p,\mathrm{stored}} \stackrel{?}{=}
 \frac{I^{(v)}_{\mathrm{total},p}-I^{(v)}_{\mathrm{ref},p}}{I^{(v)}_{\mathrm{ref},p}},\quad
v\in\{\mathrm{default},\mathrm{at\_offset}\}.
\]

后者是在**同一个MAT文件中**读取的强度，不允许跨变体借数组。六个M ×2种标准相机变体，必须各有一行可回放的结果；wide复场另行核验取样坐标。

### R04：原solve的真实几何来源仍未得到闭合

V137 `physical_forward_qualification.json` 明确记载原MAT中 `cfg.particle` 是 `gold_table`、D50/gap5 的渲染器默认块，**不代表六M真实solve几何**。现有验证以任务登记的D/h和保存的数组代替原电磁求解几何证明。缺少“原solve有效颗粒几何、材料、网格、求解配置 → 三个render →合并H5”的完整闭环。

要求回读V126缓存中的对应**原solve MAT及生成它时的有效参数**，校验颗粒D、h中心与底界面间隙、n复数、波长、物镜参数、光轴、相位、原像元尺度，并把缓存key/solve身份与各render的source关联起来。文件名、任务真值和渲染器默认的粒子配置**不构成同一solve证明**；缺字段只能标`UNVERIFIED_SOLVE_GEOMETRY`，不能猜测填充。

### R05：开发误差包络极可能混用了零位移图与偏移真值

V137开发包络为 `epsilon_dev_L2=0.10972405988601544`，来源于24个H/J/K/L已打开开发样例的最大真参数残差。软件 `tools/v137_w4_dev_envelope.py` 却固定读取：

```python

C=model.forward((D0,h0,x0,y0)).score_C
```

而正式 V131 旧24例反演配置的观测数据集是 **`at_offset/C`**，这里的 `(x0,y0)` 又是非零偏移真值。**如根 `C` 确为默认/居中图，这会产生人为的大残差；必须回读实际H5语义后才能下结论。**

如此大的 `epsilon_dev` 导致V137的兼容区间几乎全域：M01–M05为 **[30,200] nm**，M06为 **[115,200] nm**。这证明**当前采用的经验误差包络完全不足以授予唯一粒径**；不能直接把“整个D域兼容”当作物理上的严格不可辨识结论。

本轮必须在**同观测变体、同有符号静态C、同中央13×13、同未缩放L2与已核验源身份**的条件下重建开发误差；若原独立MAT观测尚未核准，则`epsilon_dev`标`NOT_QUALIFIED`，不能用它缩短区间或报告直径。

## 2. V138执行的唯一科学主线

### 冻结物理与观测含义

- 用户确认：水中悬浮、纯水26℃、520nm真空波长、14µm相机像元、50×物镜、无载玻片。
- **条件假设**：玻璃n1.5、水n1.3353、颗粒均匀有效球n1.38+0i、NA0.8、附加倍率1、物方280nm/像元、q5细采样56nm、焦面450nm。
- 目标输出是`CONDITIONAL_UNIFORM_SPHERE_OPTICAL_EQUIVALENT`，不是未经实验证实的Fe3O4真实磁芯绝对直径。材料n/k、磁芯/包覆、水动力直径、额外倍率、真实相机满阱/曝光等仍待独立测定。
- 静态正式输入为线性强度+匹配背景形成的**有符号C**。旧400Hz FFT幅值、`abs(C)`、8bit显示图不直接进入此静态forward。
- 固定F2的D/h是**物理轴张量三次复场插值**，空间是双线性查询；先形成`|Eref+Esca|²`强度，再进行子像元及曝光积分。不得退回C-map，不得让模型自由调散射振幅或相位，不得域外clip或按真D缩小搜索域。

### 阶段S2：原solve几何、same-solve宽场成像和F2插值分层

对每个可定位的M，从实际原BEM solve / 缓存key映射取回**真实求解几何和有效配置**，不是从验证登记JSON推断实物D/h，也不是使用render默认的gold_table粒子块。

在同一源中做四层互不混淆的资格：

|层|对照|目的|
|---|---|---|
|A|原MAT自身 `(Itotal-Iref)/Iref` 与 `contrast`|判定保存观测数值合法|

\[
R_i^{\mathrm{dev}}=\|F_2(D_i,h_i,x_i,y_i)-Y_i^{\mathrm{matched\ offset}}\|_2.

如果该例的原解身份、坐标或观测变体不合格，不能静默纳入“可信模型误差样本”，但应在带`NOT_QUALIFIED`原因的表中保留其数值。`epsilon_dev`仍只能是经验尺度，**不等于全域严格偏差上界或95%置信区间**。

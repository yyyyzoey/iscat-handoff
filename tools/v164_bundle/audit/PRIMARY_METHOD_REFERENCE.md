# Method reference

SciPy official least_squares documentation:
https://docs.scipy.org/doc/scipy/reference/generated/scipy.optimize.least_squares.html

The declared optimizer is bounded trust-region reflective with linear least-squares loss. SciPy cost is half the sum of squared residuals. Numerical-Jacobian calls are not reliably represented by nfev; the persisted forward attempt ledger is authoritative.

The reference is implementation documentation, not evidence that the real F2c experiment has been validated.

## 4. 冻结数学定义与优化器

模型ID：`v142-F2c-75860d222dd8e90d8dc2e31111e52ccbbb212a01c0d6a0dfe7fdbcdb241c98c3`。

场库SHA：`203e9e5f2d888503b62d48888a0f2e5365477b06101227109a3e98286f541c0f`；相机H5 SHA：`074305df1b6bbd47f7f523b05d871312309e9b6ffa390cd50d0be18296427e26`。继承V163已经审查的唯一源码换行映射，不新增白名单、不修改原源pin。

每组固定三帧、固定V146计数方差，中心13×13有符号静态对比度；不使用400 Hz幅度图代替静态观测。

\[
\bar V_p=(\sum_i1/V_{ip})^{-1},\quad
\bar Y_p=\bar V_p\sum_iY_{ip}/V_{ip},\quad
K=\sum_{ip}(Y_{ip}-\bar Y_p)^2/V_{ip}.
\]
\[
Q_J(\theta)=\sum_{ip}[C_p(\theta)-Y_{ip}]^2/V_{ip}
=Q_{\rm model}(\theta)+K.
\]
\[
Q_{\rm total}(\theta;z,\sigma)
=Q_J(\theta)+(h-z)^2/\sigma^2.
\]
优化器收到169个白化像素残差加一个高度残差，故`2*SciPy.cost=Q_model+Q_height`、`Q_total=2*cost+K`。不得把高度残差加三次，不能用无权重目标选点。

复用包内原字节`v165_objective.py`与`v152_gls_core.py`，工作站必须核验与原固定提交一致。使用：

```
least_squares(method='trf', jac='3-point', loss='linear',
              diff_step=1e-5, x_scale=[50,50,280,280],
              ftol=1e-9, xtol=1e-9, gtol=1e-8, max_nfev=200,
              bounds=([30,350,-500,-500],[200,550,500,500]))
```

四参数为D/h/x/y，仍检验h−D/2≥100nm。禁止clip、巨大残差代替异常、真值起点、调整物理模型。有限差分内部实际模型调用全部计费，不用nfev代替。

## 6. 科学方法：完全继承原定义

本课题仍为冻结静态F2c下的模拟开发试验。输入为中心13×13有符号静态对比度，不能把约400Hz复FFT幅度图代替静态输入。

\[
\bar V_p=(\sum_i1/V_{ip})^{-1},\qquad
\bar Y_p=\bar V_p\sum_iY_{ip}/V_{ip},\qquad
K=\sum_{ip}(Y_{ip}-\bar Y_p)^2/V_{ip}.
\]
\[
Q_J(\theta)=\sum_{i,p}\frac{[C_p(\theta)-Y_{ip}]^2}{V_{ip}}
=Q_{\rm model}(\theta)+K.
\]
\[
Q_{\rm total}(\theta;z_h,\sigma_h)
=Q_J(\theta)+\frac{(h-z_h)^2}{\sigma_h^2}.
\]

169个白化像素残差加一个高度残差；高度项只加一次：

`2*SciPy.cost = Q_model + Q_height`；`Q_total = 2*cost + K`。

复用原字节`v152_gls_core.py`与`v165_objective.py`。优化器保持：

```python
least_squares(
    method='trf', jac='3-point', loss='linear', diff_step=1e-5,
    x_scale=[50, 50, 280, 280],
    ftol=1e-9, xtol=1e-9, gtol=1e-8, max_nfev=200,
    bounds=([30,350,-500,-500], [200,550,500,500])
)
```

检查h-D/2≥100 nm，禁止clip、罚大数替代模型错误、真值初始化或调整物理条件。记录工作站NumPy/SciPy版本，不为此任务更新依赖。
